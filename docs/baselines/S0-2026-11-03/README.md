# S0 비교 스냅샷 — 기존 1층 도면의 미승인 상태 기록

기준 커밋: `d553799a6a45057b0db006375ae36239d849bdeb` (main).

이 디렉터리는 **GitHub에 이미 올라온 SVG/PDF/PNG/QA를 변경하지 않고** Git blob SHA·기준 검사 값·시각 크롭의 종이좌표·결함 초도 목록을 기록한다. **파일 식별용 스냅샷일 뿐 1층 도면의 설계·그래픽 품질 승인이 아니며 FREEZE가 아니다. 1층 전체의 최종 품질이 사용자에게 승인될 때까지 계속 개선한다.**

- `baseline_manifest.json`: GitHub 원본 SHA-1, 대화 업로드 이미지 별도 SHA-256, 1F 기존 19/19 QA의 범위, 3F 검증 한계, 모델 SHA 미확인 상태
- `crop_config.json`: 가로 A3 420×297mm 고정 5개 구간(모델 형상 좌표가 아닌 시트상의 시각 비교 위치)
- `visual_audit.md`: 관찰 결함과 코드/JSON 확인 결함을 구분한 S0 장부
- `tools/s0_capture_baseline.py`(저장소 루트): 동일한 5개 크롭/전체 위치 오버레이/접촉 비교판 생성; 원본을 수정하지 않음

기준 캡처는 대화에 업로드된 평면(2048×1448)에서 만들었다. 리포지토리의 PNG(1,498,531 bytes)와 대화 업로드(825,204 bytes)는 **다른 파일 바이트**다. 추후 GitHub의 원본 PNG에서 다시 만들 때 각 기준 이미지의 출처와 SHA-256을 함께 기록한다.

**독립성 한계:** .blend는 GitHub에 없고 이 세션에 제공되지 않았으므로 원본 마스터 해시 및 Blender 재렌더 재현성은 확인되지 않았다. 저장된 1F QA 19/19은 기존 실행 결과이지 새로운 QA의 실행 결과가 아니다. 3F 34/34은 README에 보고되어 있지만 세부 QA rows는 저장소에 없다.

비교용 PNG·참고 이미지·5개 크롭·실행 스크립트·로컬 unittest(4/4) 전체를 묶은 S0 ZIP은 이 작업의 결과물로 별도 제공한다. 이미지 바이너리의 재업로드를 위해 GitHub 내용을 변경하지 않는다.

다음 단계는 (1) 사용자 로컬 `.blend` hash 및 구조 원천 대조, (2) 새로운 출력 폴더에 같은 모델 재렌더, (3) 1F 상세 공간 기획 G1이다.
