## 고정 비교 크롭 5개
크롭은 `crop_config.json`의 종이 mm 좌표를 사용한다. 동일한 도곽, 가로 420×297mm, 1:500 비율의 후보에 반복 적용한다. 해당 좌표는 건축 기하 좌표가 아니다.

| ID | 영역 | 현재 직접 관찰 | 다음 수정본에서 확인할 개선 |
|---|---|---|---|
| 01 | 시장 중심 | 매대가 작은 동일 패턴으로 반복되며 안내·판매·체류 기능 차이가 약하다 | 활동별 가구 종류·군집/동선이 한눈에 구분되는지 |
| 02 | 출입구·커튼월 | 문호·유리·인접 구조선이 가까워 세부 판독이 약하다 | 문짝/호/이중 유리선이 출력 시 명확한지 |
| 03 | 코어·화장실 | UP 표시와 계단은 보이지만 6m 층고에 대응한 실제 계단 형상이 검증되지 않았다 | 모델 원천의 코어·부속실·계단·문과 동일한지 |
| 04 | 서측 캡슐 | 입구 주변 문호/곡선이 교차하며 전시 가구와 혼동될 수 있다 | 문/입구/전시 가구가 완전히 분리되어 읽히는지 |
| 05 | 공원·필로티 | 점묘·수목은 존재하지만 공원→필로티→시장의 사용 흐름이 약하다 | 보행 경로·활동 장소·진입과 휴식이 연결되는지 |

## 도면 채택 정책
1. 한 후보는 설계/모델/가구/스타일/출력 중 한 변경 유형만 시험한다.
2. 동일 5개 시트 영역에서 before/after를 함께 본다.
3. 결함을 없앴더라도 다른 영역이 나빠졌으면 `REWORK` 또는 `REJECT`다.
4. 독립 구조·피난·시트 검증을 미완료한 후보를 합격 또는 최종본으로 표시하지 않는다.
5. S0는 기존 도면을 위한 **비교 기준**이며 개선 수정이나 최종 승인이 아니다.
