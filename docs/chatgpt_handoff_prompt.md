너는 건축 도면 자동화(Blender + Python 벡터 렌더링)를 도와주는 시니어 엔지니어 겸 건축 제도 검토자다. 아래는 내가 지금 진행 중인 작업의 현황이다. 읽고 (1) 이해한 내용을 5줄로 요약한 뒤, (2) 맨 아래 "도움 받고 싶은 것"에 답해줘. 첨부한 이미지(도면 PNG, 확대 크롭)가 있으면 그것을 직접 보고 판단해줘. 로컬 파일은 네가 열 수 없으니 경로는 참고용이다.

## 1. 프로젝트
- 대한건축학회 투고 논문용 다층 상업시설(54×54 m, 지상 17층, 1층 필로티·시장 홀·나선 램프 튜브·빛 튜브·서측 캡슐·코어 4개·화장실 2곳)의 평면도를 자동 생성한다.
- 원칙: 평면도를 손으로 그리지 않고 3D 모델에서 파생한다. 그림 코드에 숫자 좌표를 쓰지 않고, 면적 숫자는 폴리곤 계산값만 쓴다.
- 파이프라인: Blender 4.2 헤드리스로 바닥 위 1.5 m에서 절단 → 절단선(shapely 벡터) → SVG/PDF/PNG/DXF → 검사 스크립트. 무거운 렌더는 Modal(클라우드)에서 돌린다.
- 입력: 1층은 태그된 마스터 모델(.blend, 객체마다 kind·name_ko), 2층 이상은 전체 건물 glb(벽·문 없음, 태그 없음).

## 2. 이번 회차에 끝낸 것 (사양서 기준)
- 종이 A3(420×297 mm) 고정. 1층(대지·도로·이웃 건물 포함)은 1:500 한 장, 상층은 1:100이라 A3 한 장에 안 들어가서 같은 축척으로 2×2 네 장 타일.
- 6단계 선 위계(종이 mm): T1 0.45 #000000(절단벽·기둥) / T2 0.18 #222222(문짝·칸막이) / T3 0.12 #444444(계단·램프·승강기) / T4 0.09 #4A4A4A(유리 커튼월) / T5 0.08 #666666(가구·위생도기·문 스윙·샤프트 X) / T6 0.05 #CCCCCC(격자·점묘·식재).
- 유리 커튼월: 흰 띠 위에 0.09 mm 이중선(월드 간격 1:500에서 220 mm), 헤어라인 멀리언 틱.
- 가구 라이브러리: 시장 섬 부스, 카페·공용 테이블, 안내 바, 필로티 플랜터 벤치, 캡슐 갤러리, 비스트로. 몸체는 #FFFFFF 불투명 채움 + 0.08 mm 외곽선이라 바닥 타일 격자가 비치지 않는다. 시장 섬은 격자 위상을 바꿔 가장 많이 들어가는 배치를 고른다(92개 → 140개).
- 충돌 해소: 문 솔버(문 스윙이 벽·다른 문·위생도기와 안 겹침, 문틀 250 mm 이격, 벽 개구 펀칭), 코어·튜브 1.8 m 이내 기둥 제거(34개 중 23개만 그림), 번호 버블이 가구·승강기·샤프트와 안 겹침, 도면 안 글자는 번호만 쓰고 이름은 범례(9항목)에 모은다.
- 상층 타일: 범례는 건물 바깥 좌/우 여백(10 m), 축척 막대는 위/아래 여백(2.6 m)에 배치해 도면 요소와 겹치지 않게 했다.
- 자동 검사(tests/verify_pipeline.py): A3·축척, 가구 흰 채움, 가구 선 ≤0.12 mm, 커튼월 선 ≤0.18 mm, 충돌 지표 0, 번호 숫자, 확대 크롭 800×800. 결과: 1층 19/19, 3층 34/34 통과.

## 4. 아직 안 풀린 문제
1. 2층 이상은 glb에 벽·문이 없어 벽체 없는 도면이다. 1층 마스터 같은 태그 모델이 상층에도 필요하다.
2. 상층 가구는 이름 키워드 기반 설명용 배치다. 3층 슬라이스에 `source` 플래그가 없어 코어 번호가 안 붙는다.
3. A1 합성기(04_hybrid_compositor.py)는 A3 잠금을 아직 따르지 않는다. DXF는 CAD 엔진이 따로 만들어 새 가구·커튼월 이중선이 들어가지 않는다.
4. 피난계단 형태 충돌: 내 규칙 문서는 4갈래 ㅁ자형(6×6 m 코어에서 층고 6 m를 오르려면 ㄷ자형으론 부족), 도면 그래픽 지시는 U자형이다. 지금은 U자형으로 그렸다.
5. 확대 크롭 `crop_curtainwall_furniture.png`는 주출입구 쪽 필로티 광장을 보여주며 시장 가구는 거의 안 나온다.

## 5. 도움 받고 싶은 것 (아래에서 내가 고른 번호에 답해줘)
A. 첨부한 도면을 건축 제도 관점에서 비판적으로 검토해줘: 선 위계가 읽히는지, 커튼월이 섬세한 이중선으로 보이는지, 가구 배치가 시장·카페·안내 구역답게 보이는지, 여전히 조잡하거나 겹쳐 보이는 곳은 어디인지.
B. 상층에 벽·문이 없는 glb만 있을 때, 벽과 문이 있는 상층 평면을 신뢰성 있게 만드는 방법(1층 마스터에서 코어·화장실을 복제할지, 규칙 기반으로 생성할지 등)을 2~3안으로 비교하고 하나를 추천해줘.
C. 6×6 m 코어(층고 6 m)에 맞는 피난계단 형태(ㅁ자 4갈래 vs U자)를 법규(건축법 시행령·피난방화규칙) 관점에서 검토해줘. 확신 없는 법 조항은 확신 없다고 표시해줘.
D. 위 파이프라인 코드 구조에서 개선할 점(검사기와 그림 코드 분리, 결함 장부 방식 등)을 제안해줘.
