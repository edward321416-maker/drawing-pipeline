# C-T14F 도면집 V3 중간본 (INTERIM · NOT FROZEN)

`Candidate_V3_interim.pdf` (30쪽 A3, 2.5 MB)는 **V2 PDF에 보정을 적용한 중간본**이다. 최종 V3가 아니다. 전체 감사와 나머지 개선은 아직 진행 중이다.

## 적용한 것 (전부 `patch_log.json`에 쪽·위치·전후 문구가 기록됨)

| 번호 | 내용 | 결과 |
|---|---|---|
| F-01 | 호출 기호의 축척을 시트 레지스트리(`docs/t14e_v2/sheet_index.json`)에서 읽어 다시 씀 | 6곳 정정: P-102 `D-407`, P-105 `D-410` (1:50 → 1:100). **감사 지적에 없던 곳도 찾음**: 입면도 E-201~E-204(10~13쪽)의 `D-410`도 1:50이었음 |
| F-02 | 상세도 D-401~D-410(19~28쪽) 10장에 실제 그래픽 스케일바 추가 | 1:50은 5 m = 100 mm, 1:100은 10 m = 100 mm. 벡터 실측 100.000 mm |
| F-10 | 제목란 판 표기 V2 → V3(중간본), 프로젝트 코드 C-T14D → C-T14F, 표지·A-900 문구 | 새로 쓴 문구는 실제 공백이 있어 텍스트 추출이 정상 |
| F-10 | 글꼴 | V2는 맑은 고딕 전체 글꼴 복사본을 여러 번 포함해 17.1 MB였음 → 사용 글리프만 남겨 2.5 MB. 모든 글꼴 임베드·서브셋 |

A-003(4쪽, 사용자 제공 1층 배치도)은 한 화소도 바꾸지 않았다.

## 확인한 것 / 확인하지 않은 것

- 확인함: 30쪽을 V2와 화소 비교했을 때 변경은 기록된 위치 안에만 있다(4쪽 0 화소). 스케일바 10장의 길이를 벡터와 600 dpi 래스터로 측정했다. 글꼴 112개가 모두 임베드·서브셋이다.
- **확인하지 않음**: 보정한 쪽을 300 dpi로 전부 눈으로 검수하지 않았다(호출·스케일바·제목란 일부만 확대 확인). V2 전체의 쪽별 시각 감사, 감사 지적 F-03~F-09·F-11~F-15, 1:200 A1/분할 출력, 층 커버리지, 가구 검사는 **아직 하지 않았다**.
- 모델 원본(`GMC-ZZ-ZZ-M3-0701.glb`)과 V2 실행 폴더가 저장소에 없어 모델에서 다시 절단·출력하는 작업은 `BLOCKED_MISSING_SOURCE`다. 이 PDF는 V2 PDF를 보정한 것이지 모델에서 새로 만든 것이 아니다.
- 보정으로 쓴 문구는 나눔바른고딕(OFL)이고 V2 본문은 맑은 고딕이라 제목란 한 줄의 글꼴이 다르다.

## 다시 만들기

```
python -I tools/t14f/patch_v2.py --out <출력>.pdf --log <로그>.json
```

글꼴은 `tools/t14f/fonts.py`가 찾는다(`T14_FONT_DIR` → Windows 글꼴 → Linux/macOS 시스템 글꼴 → fontconfig). 글꼴 파일은 저장소에 넣지 않는다. 필요한 패키지: pymupdf, numpy, scipy, fonttools.
