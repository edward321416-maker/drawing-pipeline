## 부록: 라이선스·절차 관련 주의

1. **Commons 사진은 거의 CC BY-SA(저작자 표시 + 동일조건변경허락).** 렌더나 발표 자료에 사진 자체를 넣으면 저자 표시와 SA 조건이 따른다. 참고용으로만 보고 산출물에 복제하지 않는 한 SA 부담은 없다. 사진 대장에 저자·라이선스 URL이 있다.
2. **초상권:** R07 R09 R10 R14에 식별 가능한 사람이 있다. 내부 참고용으로만 쓰고 외부 배포 금지.
3. **DDP·상표:** R04의 Commons 분류에 'NoFoP-South Korea'가 붙어 있다. DDP 형태와 외피, 롯데·두타·밀리오레·맥스타일 간판은 복제하지 않는다.
4. **OSM은 ODbL.** 센서스 JSON이 OSM 파생 데이터베이스이므로 외부 공개 시 `(c) OpenStreetMap contributors` 표시와 동일조건 공유 조건을 확인해야 한다.
5. 서울시 기사 3건은 공공누리 제4유형(출처표시, 상업적 이용 금지, 변경 금지). **사실만 인용**했고 문장·이미지는 복제하지 않았다. 뉴데일리, SkyscraperPage, 집품(zippoom)은 저작권 보유 자료로 수치만 인용했다.
6. **절차상 실수:** Commons 요청의 User-Agent 헤더에 사용자 이메일을 '연락처'로 넣어 보냈다(35건 모두). 사용자 이메일을 무관한 서비스에 보내지 말라는 규칙을 놓친 것이며, 되돌릴 수 없다. 이후 스크립트에서는 제거했다.
7. 요청 수: Commons API/다운로드 총 35건(검색 20, 이미지 15; 이미지 1장은 관련 없어 삭제, 14장 보관). 합계 다운로드 약 9.0 MB. 별도로 웹 검색 6회, 페이지 열람 5회(서울시 3, SkyscraperPage, 뉴데일리)를 했다.
