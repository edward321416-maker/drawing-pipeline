# 도면집 V2 — 해결한 시각·구성 문제 (V1 대비)

기준: V1 도면집 `Drawing_Set_Candidate_V1.pdf`(27쪽)를 다시 읽고(재감사), 사용자 요구(V2 명세 0~8)와 대조해 찾은 문제와 해결 방법이다.
"해결"은 이번에 만든 시트를 눈으로 확인하고 `tools\t14e_book_qa.py`가 시트 텍스트·SVG를 다시 읽어 통과한 것만 적는다.

## D. 상세

사용자가 V1 상세를 "너무 못 만들었다"고 삭제했으므로 **새로 설계**했다. 모든 상세는 평면(왼쪽) + 단면(오른쪽) + 확대 위치 키플랜 + 치수·근거 표로 구성하고, 값은 모델 메시·1층 마스터에서 읽은 것만 쓴다(재료·접합 임의 작도 없음).

## E. 정직하게 남긴 한계

- 평면 축척은 **1:200이 아니라 1:250**이다. A3에 54 m 건물(1:200에서 270 mm)과 치수 3열·축선·우측 범례·제목란을 함께 담을 수 없다. 1:100 타일 분할 또는 A1 대판은 사용자 결정 대기(A-900 U-05).
- 상층에는 벽·문·창·재료가 모델에 없다. 평면은 LEVEL S(기둥·튜브·코어·층판 + 제안 가구)이며 가구는 PROPOSED_ONLY다.
- 클라우드(Modal·Claude API)는 쓰지 않았다. 신규 결제 없음.
- 평면·입면·단면 PDF의 텍스트 추출 시 공백이 빠진다(cairosvg 글리프 출력). 화면·인쇄에는 영향 없음.
