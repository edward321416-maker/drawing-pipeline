# 도면집 V2 — 아직 결정하지 않은 설계·도면 사항

이 도면집은 **CANDIDATE V2 · NOT FROZEN**이다. 아래는 모델에 근거가 없거나 사용자 결정이 필요해 도면에 확정하지 않은 항목이다. (도면집 A-900과 같은 번호)

| 번호 | 항목 | 현재 처리 | 필요한 결정 |
|---|---|---|---|
| U-01 | 상층 외벽·구획벽·실내 문·창·화장실·피난 경로 | 모델에 없음 → 평면은 LEVEL S, 그리지 않음 | 상층 벽·문 체계를 설계할지 |
| U-02 | 캡슐(서측·동측) 출입구·문 | 모델에 문 없음, 사용자 미승인 → 벽을 닫아 둠(D-405) | 출입구 위치·형식 |
| U-03 | 코어 A~D 상층 내부(계단·부속실·승강기) | GLB에는 외곽 벽만. D-404는 1층 마스터만, 상층은 UNRESOLVED | 상층 코어 내부 설계 |
| U-04 | 외피(A-FACD) 성격과 접합 | 모델 부재 형상만 표시(D-406) | 커튼월/벽/난간 구분·접합 |
| U-05 | 평면 축척 | 1:250 사용(A3 한계). 1:200 요구와 다름 | 1:100 타일 분할 또는 A1 대판 중 선택 |
| U-06 | 8F~9F·13F~14F 공통 평면 | 면적·프로그램 동일, 수직 개구만 다름(`CIRCULATION_ONLY`, 합쳐 한 장 + 차이 표기) | 이 공통 처리를 받아들일지, 층별로 분리할지 |
| U-07 | 4F·5F 평면 | 3F와 같지 않음(프로그램·층판 차이) → 합치지 않고 미발행 | 필요 시 층별 평면 추가 |
| U-08 | 가구·프로그램 배치 | 전부 PROPOSED_ONLY | 어느 안을 설계로 채택할지 |
| U-09 | 치수 | 모델 값을 10 mm로 반올림. 구조 두께·재료 규격은 모델에 없어 미표기 | 구조 규격 자료 |
| U-10 | 선큰 계단 | 단 수·방향·윤곽만(폭·단높이 속성 없음), 지반 미표시 | 선큰 단면 설계 |
| U-11 | 화물 승강기 | 형상만, 카·기계·하역 동선 없음 | 화물 동선 설계 |
| U-12 | 입면의 대지 지형·옹벽·이웃 건물 | 모델에 없음, GL = 1F FFL만 | 대지 모델 추가 여부 |
| U-13 | 배치도 A-003 | 사용자 제공 1F_CleanLine_FIXED를 수정 없이 수록(승인 전 후보) | 1층 최종 승인 |
| U-14 | 클라우드 사용 | 미사용, 신규 결제 없음 | 필요 시 별도 승인 |
| U-15 | PDF 텍스트 검색 | 공백이 빠져 추출됨 | 검색 시 공백 없이 입력 |

## 하지 않은 일

- 원본 저장소(`vertical-commercial-pedestrian-flow`)·1층 사용자 제공 파일·V1 산출물은 건드리지 않았다.
- 커밋·푸시·병합·FREEZE 없음. 신규 결제·계정 연결 없음.
