# 미해결 건축 설계 결정

V4.1은 편집 개선판이며 아래 항목을 새로 확정하지 않았다.

- 상층 구획벽·문·피난 경로
- 코어 내부 계단·부속실
- 선큰 계단 승인 치수
- 외피 접합·재료·단열
- 화물 승강기 장비·운영
- 지붕 개방/폐쇄·방수·배수
- 프로그램 볼륨 투영과 법정·전용면적의 대응
- 원본 GLB 재확인

원본 GLB가 현재 실행 환경에 없으므로 GLB에서만 확인 가능한 정보는 계속 `BLOCKED_MISSING_SOURCE`다. 이번 편집판은 `model_world.npz` 캐시와 기존 검증 도면의 범위 안에서만 도형을 사용했다.
