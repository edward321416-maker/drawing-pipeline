## 2. 신규 독립 버그 — WC 슬라이딩 문 직렬화 누락

코드에서 직접 확인:
- `engine/symbols/restroom.py`의 `_unisex()`: 화장실 B 장애인 큐비클의 슬라이딩 문 정의.
- 같은 파일 `_split()`: 화장실 C 장애인 독립실의 슬라이딩 문 정의.
- `all_doors(rr)`: 의도된 WC 문은 B 2개(공용 스윙, 장애인 큐비클 슬라이딩) + C 3개(남 스윙, 여 스윙, 장애인 슬라이딩)로 5개.
- `_sliding_door()`는 `swing=None`, `leaf=LineString`, `travel=LineString`.
- `engine/master/build_master.py`는 `if d.swing is not None:`만 3D 문 객체를 생성하므로 슬라이딩 문 2개가 누락됨.
- 현재 11개 모델 문 중 WC 문은 3개다. 기존 도어 형상과 폭을 유지한 채 슬라이딩 문까지 모델에 포함하면 코어 8 + WC 5 = **13개 문 객체가 기대된다**. 아직 패치하지 않았으므로 13개는 결과가 아니라 기대값이다.
- 기존 `restroom.py`의 화장실 C 장애인문이 놓인 벽에는 `R(3.3, D-tw, 3.3+sliding_door_w_m, D+tw)`로 개구 형상이 이미 정의돼 있다. **모델 직렬화 누락과 실제 유효 통과폭·법규 적합성은 별개**다.

1. 기존 테스트를 유지하고 새 회귀 테스트로 슬라이딩 문 2개가 3D 모델에 나타나지 않는 증거를 먼저 만든다.
