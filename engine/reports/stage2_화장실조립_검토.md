## 2. 조립한 것

마스터의 사각 화장실 벽 8개를 승인된 심볼에서 만든 객체로 바꿨다.

| | 화장실 B (공용·장애인 겸용 1실) | 화장실 C (남/여/장애인 분리) |
|---|---|---|
| 방 외곽 벽 | 1 | 1 (+ 칸 사이 벽 1) |
| 큐비클 칸막이(가는 선, `thin`) | 있음 | 있음 (둘을 합쳐 12개) |

- 상세 평면은 모델의 방 태그(`wc_id`, `program`, 외곽)에서 같은 심볼을 다시 만들어 세면대 볼, 휠체어 회전 원, 문 호·문짝을 그린다. 벽·칸막이·위생기기는 모델 객체로 이미 그려지므로 두 번 그리지 않는다.
- 큐비클 칸막이는 선 두께 0.6(`AGENTS.md` §3.2), 외곽 벽은 구획벽 두께로 그려진다.

## 4. 검사 결과

- TAG, G1, G2, G3(모델), G4, G5, G6, T1~T4 위반 0건. 엔진 테스트 143개 통과.

- 원본 중간발표 데이터의 충돌 기록(코어 B 홀문 ↔ 화장실 B)은 화장실 객체가 늘면서 벽·칸막이·양변기 3건으로 갈라져 기록된다. 사용자 결정(코어 B 홀문 서쪽 이동)으로 해소된 상태는 그대로다.

## 5. 알아 두실 점

1. **화장실과 이웃 코어 사이 틈 — 해소됨(7항).** 화장실 C는 코어 C와 0.325 m, 화장실 B는 코어 B와 0.225 m 떨어져 있었다(바깥 벽면 기준, 중간발표 원본 위치). 사용자가 권장안(맞닿게 이동)을 승인해 옮겼다.
2. **남·여·장애인 라벨.** 1:300에서는 각 칸이 작아(8~13㎡) 글자가 칸 밖 지시선으로 붙었다. 칸 안에 넣으려면 1:100 이상의 확대 도면이 필요하다.
3. **슬라이딩 문(장애인 칸).** 모델에는 스윙 영역이 없어 모델 수준 G3로는 검사되지 않는다. 심볼 수준 R2·G3와 기둥 포함 재검사(위 4항)로 확인했다.
4. **위생기구 법정 수량**은 확인하지 않았다(앞서 알린 그대로).
5. 튜브, 보이드는 아직 단순 표기다(상세 평면 부제에 "상세 적용: 코어·화장실").

## 7. 후속: 화장실을 코어에 맞닿게 이동 (사용자 승인 2026-11-01)

| | 이동 | 결과 |
|---|---|---|
| 화장실 B | 북쪽으로 0.225 m (y 41.4~46.7 → 41.625~46.925) | 코어 B 남쪽 벽면과 맞닿음 |
| 화장실 C | 남쪽으로 0.325 m (y 6.4~12.2 → 6.075~11.875) | 코어 C 북쪽 벽면과 맞닿음 |

- 방 크기·구성은 그대로다. 이동은 `D:\Users\admin\Desktop\2학기 논문\도면\00_엔진\model\design_adjustments.json`의 `restroom_shift`에 기록했고, 마스터 빌더·시트 빌더·테스트가 같은 함수(`restroom_world_bounds`)로 같은 위치를 쓴다. 원본 위치는 `adjustments={}`로 다시 만들 수 있다.
- 이동 후 화장실 B에서 화장실 규칙(R2)이 한 번 걸렸다. 기둥 `Col_53.4_45`가 진입 통로 검사 영역의 동쪽 끝 모서리를 0.01㎡ 침범한 것이다.
  - **먼저 시도한 안(장애인 큐비클 깊이 2.2 → 2.3 m)은 버렸다.** 규칙은 통과하지만 통로 띠가 좁아져 "화장실 22㎡" 라벨이 방 안에 들어가지 못하고 지시선으로 방 밖에 놓였다(깊이 2.25 m까지는 라벨이 들어가고 R2는 걸리며, 2.27 m부터 R2는 통과하고 라벨은 나간다).
  - **채택한 안:** 승인된 심볼(깊이 2.2 m)은 그대로 두고, 진입 통로 검사 영역의 동쪽 끝을 "슬라이딩 문 열림 끝에서 0.3 m"까지로 정리했다(`symbols\restroom.py`). 그 동쪽 구석은 동선이 이어지지 않는 자리다. 통로 폭은 1.71 m로 기준 1.2 m 이상이며, 통로 위에 물건을 두면 여전히 걸리는 것을 테스트가 확인한다. **이것은 검사 영역을 줄이는 조정이므로 알려 드린다.** 눈에 보이는 심볼 배치는 승인본과 같다.
