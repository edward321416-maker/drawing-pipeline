# WP0 R9 A2 기술도면집 · 독립 검수

비공개 검수 브랜치의 자료입니다. 2F D와 7F C·D의 상부 접합을 검토한 원본 도면집에서 아래 페이지를 추출했습니다. 사진 도판은 Blender에서 직접 출력한 렌더와 연결합니다. 구조 정착, 법규, 실제 장비 운영 및 외부까지의 피난은 검증 보류입니다.
