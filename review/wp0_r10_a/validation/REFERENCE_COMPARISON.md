# R10-A 참고본 대조 결과

로컬 기준 PDF를 직접 렌더링했습니다. 같은 크기의 화면에서 도곽과 제도 위계를 대조했고, 동일한 물리 영역 128×108 mm를 220 DPI로 렌더하여 글자·치수선·부재 경계를 비교했습니다. 참고본 내 레벨·부재 크기는 R10-A의 설계 입력으로 옮기지 않았습니다. 화면과 PDF 벡터를 검수했습니다. 실제 프린터 테스트는 미실시입니다.
