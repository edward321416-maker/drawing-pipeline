## 2. 전환할 스타일 원칙 (근거와 설계 제안을 구분)

### S1 — 강한 구조체 위계, 조용한 가구

- **시각적 근거:** HYBE 8–16층 평면에서 코어와 기둥이 검은색 실체로 정리되고, 세부 가구 모듈은 상대적으로 중간 회색을 사용한다.
- **우리 도면 제안:** 코어·기둥·구조 절단은 어두운 포셰(0.45mm), 주요 문/벽 0.18mm, 가구 외곽 0.10mm, 세부 0.07mm, 조경 0.05–0.09mm. **숫자는 원본 FHHH에서 추출한 치수가 아닌 우리 출력 프로파일에 맞춘 권장값**이다.
- **검증:** 1:500 A3 실물 100% 화면/인쇄에서 구조→가구→조경 구분; 구조 소스 ID 누락/은폐 0.

### S2 — 공간과 사용 행위가 먼저, 정보는 나중

- **시각적 근거:** 확인한 HYBE 평면은 반복되는 모듈/가구가 구조 그리드에 정렬되며 빈 공간이 명료하게 남는다.
- **우리 제안:** 승인된 시장 M01~M06, 필로티 P01~P04, 서비스 S01~S04, 캡슐 C01~C04는 유지. 시장은 동선을 먼저 비우고 판매대·시식/체류·팝업의 가구 유형을 차별화한다. 같은 시장 모듈의 기계적 전면 반복을 금지한다.
- **검증:** 프로그램별 공간/실물 가구 inventory, 시야/보행 그래프, 주·부통로 침범 0.

### S3 — 단위 모듈은 시스템이고 장식이 아니다

- **출처에 있는 사실:** HYBE 사무 가구·공간은 500×500mm 그리드를 유연한 가구 배치·조합에 활용했다.
- **우리 제안:** 내부 매대·진열장 치수·가구 모듈을 0.5m 계획 격자에 **가능한 경우만** 정렬한다. 곡면 캡슐·램프·피난 동선은 격자를 억지로 강제하지 않는다.
- **검증:** 사용자 승인 구조 좌표·피난 동선을 변경하지 않은 상태에서 가구 정렬/배치 충돌만 시험.

### S4 — '찌글한 선'과 조경 장식은 다른 문제

- **우리 코드에서 직접 확인:** `monograph_plan_renderer.py::wobble_ring()`은 의도적으로 불규칙한 식재를 생성하고, `architectural_plan_renderer.py::bezier()`는 곡선을 선분으로 근사한다. 일부 파동은 PNG 변환이 아니라 **입력 기하 자체의 디자인**이다.
- **우리 제안:** 물리적 대지/동선 경계는 데이터에서 다시 그리되, 조경 기호는 변형 모양을 줄이고 일정한 원형/부드러운 벡터 패턴으로 표기. 단, 원래 보행 경로 선형이나 장애물은 단순화해서 이동시키지 않는다.
- **검증:** 기존/개선 SVG를 800% 확대. 선 중복, 톱니 각도, 짧은 세그먼트 수·원본 기하 편차 보고.

### S5 — 최소한의 주석과 높은 인쇄 가독성

- **우리 도면에서 직접 관찰:** 우측 프로그램 표와 범례가 크게 자리하고, 세부 텍스트/가구는 A3 1:500에서 작은 이미지로 보인다.
- **우리 제안:** 시트 좌측~중앙의 건물 평면을 먼저 읽히게 만들고, 우측 표는 프로그램 구분에 필요한 항목만 남긴다. 도곽/축척/북향/범례를 독립 계층으로 정리한다.
- **검증:** 실제 인쇄 페이지 크기 A3 420×297mm, scale=1:500, 프로그램별 텍스트 겹침/잘림 0.

## 4. Claude가 적용할 렌더 파이프라인

1. 기준 모델·1F 슬라이스·현재 SVG와 V2-B PNG의 SHA256 및 Git HEAD 기록.
2. 현재 출력의 외피/구조/가구/조경 경계를 source feature ID별로 감사. 34개 기둥이 실제로 어디에 나타나는지 선명한 레이어로 검증.
3. **그래픽 속성만** `style_tokens.proposed.json`을 참고하여 카테고리별로 조절. 주요 구조·공공 동선·프로그램 구획 기하는 그대로.
4. SVG로 도면 정본을 생성하고 1:500 A3 PDF·300dpi 이상의 PNG를 변환. 기존 PNG 전체를 밑그림으로 깔지 않는다.
5. 후보 `ReferenceStyle_A`(흑백 균형/구조 강조)와 `ReferenceStyle_B`(조경 단순화/가구 강조) 생성. 두 후보의 기하 feature 집합은 동일해야 한다.
6. 5개 비교 크롭(시장 북측, 코어, 서측 캡슐, 필로티/조경, 범례), 실제 PDF 확대, 컴퓨터 기반 선 정합 검사 및 사용자 시각 판단.
7. 상대 비교에서 나빠진 항목은 REWORK. 사소한 스타일 최적화는 에이전트 재량, 건축 모델 개구/구조 변화는 사용자 승인 후 별도 작업.

## 5. 금지/보류 목록

- 원본 사진/도면을 사용자의 새로운 도면이나 논문 본문에 직접 복제·재배포하지 않는다. 내부 분석용으로만 보관하며 출처/저작자 표기를 유지한다.
- 프로젝트 자료를 허용 없이 공개 GitHub 저장소에 업로드하지 않는다. 저장소에는 **분석 지침·토큰·원본 출처 URL·해시**만 유지한다.
- 원본 사이트 전체 이미지가 확보됐다고 주장하지 않는다. 스크립트 실행 결과 `capture_manifest.json`의 다운로드 성공/누락 수로 판정한다.
- 현재 프로젝트의 18개 프로그램 승인과 1F 최종 도면 FREEZE는 별개의 상태다.
